## Reproduction helpers

`scripts/inspect-saved-lyrics.cjs` accepts the source profile and exact title,
copies only Local Storage into a unique ignored profile, blocks renderer resources,
and prints matching-document metadata. Concurrent source writes can make a copied
snapshot inconsistent; failure is not permission to restart/modify the user's app.

`scripts/compare-current-lyrics.mjs` accepts that snapshot, calls the existing
LRCLIB/NetEase/Kugou provider implementations under a12s abort budget, and compares
unique exact-text timestamps. Temporary exports of private provider functions are
confined to the generated ignored diagnostic bundle, never the production bundle.
